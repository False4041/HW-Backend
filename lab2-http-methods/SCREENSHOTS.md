Код и коллекция подготовлены. Существующие скриншоты включены в README. Снимки следующих проверок нужно сделать самостоятельно; результаты не подменены изображениями.

1. Перезапусти сервер игры: `.\venv\Scripts\python.exe app.py`.
2. Во втором терминале запусти практический пример: `.\venv\Scripts\python.exe example.py`.
3. Импортируй `Lab2.postman_collection.json` в Postman.
4. Выполни коллекцию целиком по порядку. Перед повторным запуском перезапусти оба сервера.

| Раздел коллекции | Нужные снимки |
| --- | --- |
| Практический пример | GET списка, GET по ID, POST, PUT, DELETE, ошибка 404, ошибка 400 |
| Игры: получение, поиск, сортировка, страницы | Поиск, сортировка asc и desc, пагинация, совмещённый запрос, неверный query-параметр |
| Игры: создание, изменение, удаление | PUT 200, GET после PUT, PUT 400, PUT 404, DELETE 204, GET после DELETE 404 |
| Автоматические проверки Postman | Test Results с зелёными тестами и итог Collection Runner |

На снимке запроса должны быть видны метод, адрес, отправленное тело (для POST/PUT), код статуса и ответ. У DELETE 204 тело ответа пустое. Снимки прежних GET/POST уже есть в отчёте.

Присланные дополнительные снимки можно добавить в разделы README «Практический пример», «Изменение и удаление», «Поиск, сортировка и пагинация» и «Проверки и материалы Postman».
