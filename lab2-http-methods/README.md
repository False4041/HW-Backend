## Теория

CRUD - это создание, чтение, изменение и удаление данных. В работе для этих действий используются POST, GET, PUT и DELETE. Flask связывает адрес и метод запроса с функцией.

Данные хранятся в списке Python. После перезапуска сервера изменения пропадают. Ответы возвращаются в формате JSON.

### Изменение и удаление

PUT меняет данные игры и возвращает 200. DELETE удаляет игру и возвращает 204 без тела ответа. Если игры нет, оба метода возвращают 404.

### Поиск, сортировка и страницы

Параметр `search` ищет игру по названию, `sort` и `order` задают сортировку, `page` и `limit` выбирают страницу.

- `/games?search=mine` - поиск Minecraft.
- `/games?sort=rating&order=desc` - рейтинг по убыванию.
- `/games?page=2&limit=1` - вторая страница по одной игре.

Неверные параметры возвращают 400.

## Контрольные вопросы

**1. Чем отличаются PUT и PATCH?**  
PUT заменяет все данные записи, PATCH меняет только переданные поля.

**2. Как сделать поиск по коллекции?**  
Получить `search` из адреса и выбрать записи, в названии которых есть этот текст.

**3. Как работает сортировка?**  
Записи сравниваются по выбранному полю. `asc` задаёт возрастание, `desc` - убывание.

**4. Как работает вывод по страницам?**  
`page` задаёт номер страницы, `limit` - число записей. Начало страницы вычисляется как `(page - 1) * limit`.

**5. Какой статус возвращается при ошибке проверки данных?**  
400 Bad Request с сообщением об ошибке.
